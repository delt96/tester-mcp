# availability — E2E 전 구간 데이터 가용성 조사

**목적**: 외부수신문서 1건을 의안으로 등록해 공포까지 태우는 전 구간을 한 번 돌리려 할 때,
**어느 단계에서 데이터가 없어 막히는지** 미리 알아내는 진단 스위트다. 기능 검증이 아니라 **사전 조사**다.

기능 시나리오와 다른 점:

- **읽기 전용** — 등록/수정/삭제/서명을 하지 않는다. 화면을 열고 존재만 확인한다.
- **`on_failure: continue`** — 한 단계에 데이터가 없어도 멈추지 않고 끝까지 훑는다.
- **FAIL이 곧 결과** — `assert_visible` 실패 = "그 단계에 진행할 데이터가 없다"는 조사 결과다.
  PASS/FAIL 목록 자체가 산출물이므로, FAIL을 버그로 읽지 말 것.

## 2026-08-11 수동 진행에서 이미 확인된 사항

이 스위트가 자동으로 잡아내야 할 것들을, 같은 날 수동으로 전 구간을 태우며 먼저 확인했다.

| 단계 | 확인 결과 |
|---|---|
| 외부수신 → 의안등록 | 정상. 등록 화면 URL에 `extDocId`·`waitId`가 붙고 외부문서가 첨부공문으로 자동 연결됨. 파일은 외부문서 첨부 중에서 고른다 |
| 의안 등록 | 저장 시 확인창 없이 이첩 모달이 뜨고 **법무실 부서장이 수신자로 자동 지정**. 번호 `6-6972/26` 채번 |
| 법률검토 | **주 이행자로 지정돼야 [의견서 작성] 버튼이 나타난다.** 이행자로만 추가하면 안 보임 |
| 의견서 등록 | **공문 파일(`Расмий документ`)이 필수.** 없으면 오류 메시지 없이 조용히 등록되지 않음 |
| 이행요청 서명 | 요청자 본인을 서명자로 지정하면 서명대기 없이 즉시 `Жөнөтүлдү`. 타인 지정 시 `Кол коюу күтүлүүдө` |
| 이행요청 수정 | 한 번 서명한 뒤에는 **서명자 필드가 비활성**된다 |
| 서명 승인함 | admin 계정 기준 **0건** — 다른 계정이 admin을 서명자로 지정해야 내용 있는 화면이 된다 |
| 정부이송 상세 | **서명자로 지정된 계정에서만 진입**된다. gduser1은 목록에서 상세로 못 들어감 |
| 부재 배지(EA-10) | 휴가·병가 중인 사용자가 없어 확인 불가 |
| 문서작성 임시저장(EA-03) | `/main/letter/insert` 화면에 임시저장·불러오기 버튼이 **없음** — 구현 여부 확인 필요 |
